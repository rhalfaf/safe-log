# Safe Log

> [!WARNING]
> Projekt jest w trakcie tworzenia. API, sposób konfiguracji i zachowanie biblioteki mogą ulec zmianie. Biblioteka nie jest jeszcze gotowa do użycia produkcyjnego.

Safe Log to biblioteka Java służąca do bezpiecznego tworzenia tekstowej reprezentacji rekordów. Umożliwia oznaczanie wrażliwych komponentów adnotacją `@Sensitive` i maskowanie ich przed zapisaniem w logach.
